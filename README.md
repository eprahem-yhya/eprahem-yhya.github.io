# eprahem-yhya.github.io

My CV, as a page rather than a document.

**Live:** https://eprahem-yhya.github.io/

`index.html` is the whole CV — no build step, no framework. It prints to a
clean A4 sheet, and `Eprahem-Yhya-CV.pdf` is the rendered copy for anyone whose
browser will not print (Telegram's in-app browser, for one). `python make_pdf.py`
rebuilds the PDF and the link-preview card `og.png` (from `og.html`).

- [LadderGuard, MT5 trade manager and account guard](https://eprahem-yhya.github.io/ladderguard/)
- [Signal channel audit](https://eprahem-yhya.github.io/channel-audit/)
