Automated Trading System

Private source

An end-to-end pipeline that reads trading signals from Telegram, classifies them with an AI model, and executes them on MetaTrader 5. My own concept, built from scratch and developed continuously over four months.

  • Classifies every incoming message into one of fifteen intents — new order, stop-loss move, partial close, cancellation — and forwards only what is executable.
  • Refuses unsafe instructions by design: an order whose stop sits on the wrong side of entry is rejected, and a request to remove a stop is never obeyed.
  • Web dashboard on FastAPI with a React front end, reading a shared SQLite database in WAL mode alongside the live bot.
  • Three-layer access: bcrypt password, one-time code over Telegram, then a signed session cookie. Reachable remotely through a Cloudflare tunnel.
  • Watchdog and heartbeat monitoring, scheduled backups, and automated weekly performance reports.

Python · Telethon · MetaTrader5 API · OpenAI API · FastAPI · React · SQLite · Cloudflare Tunnel

AMBER — Coffee House

View live

A landing page built around a scroll-driven 3D scene: a coffee bean turns and rises, a porcelain cup grows into its place, steam lifts once there is something to rise from.

  • Every asset is generated in the browser — the latte art and particle sprites are drawn to a canvas at runtime, so the page ships no images.
  • Environment-mapped reflections and filmic tone mapping, which is what separates a 3D object from a photograph.
  • Full English / Arabic switching with RTL layout, without a reload or a second page.
  • Degrades on purpose: no WebGL, a reduced-motion preference, or a low-memory device gets a static composition instead of a page that stutters.
  • One HTML file, no build step, no framework.

Three.js · JavaScript modules · CSS · GitHub Pages

MAISON NOOR — Storefront

View live

A luxury fragrance storefront with a photoreal 3D hero and a working cart, built as one static page.

  • A real glTF bottle rendered with true glass transmission and refraction, lit by an HDRI environment map so every highlight reflects an actual place.
  • The brand label is drawn to a canvas at runtime and mapped onto the model — what stops a licensed asset from looking licensed.
  • Cart with size variants, quantity, live totals and badge count; the drawer traps focus, restores it on close, and closes on Escape.
  • Palette, type pairing and motion tier resolved from a design-intelligence dataset rather than chosen by eye.
  • Bilingual EN / AR including drawer direction, 44px minimum targets, visible focus, and motion disabled on request.

Three.js · glTF · HDRI lighting · JavaScript · CSS · GitHub Pages
