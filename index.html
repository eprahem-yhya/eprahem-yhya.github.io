Automated Trading System

Private source See the control panel See the product page

An end-to-end pipeline that reads trading signals from Telegram, classifies them with an AI model, and executes them on MetaTrader 5. My own concept, built from scratch and developed continuously over four months.

  • Reads a private signal channel through the Telegram API and, as a second path, through Telegram Web (Playwright + Chrome DevTools Protocol). Classifies each message into one of fifteen intents and forwards only what is executable.
  • Executes on MT5 with partial closes, break-even, a stop that trails one target behind, end-of-day close by server clock, risk caps, and rejection of any order whose stop is on the wrong side of entry. A request to remove a stop is never obeyed.
  • Mirrors channels to other channels through a bot, including edits and deletions.
  • Tick-level backtest in Python (NumPy) of 261 historical signals over five weeks, used to choose the exit rules.
  • Runs on a Windows VPS and heals itself: a scheduled watchdog restarts failed services and alerts on a stale feed; sessions are backed up daily; a position-size rule is applied once per trading day; a weekly report is sent. 50+ unit tests cover the trading engine.
  • FastAPI and React dashboard on a shared SQLite database (WAL), behind bcrypt, a one-time Telegram code and a signed cookie. A read-only preview is public; the source stays private.

Python · Telethon · Playwright · MetaTrader5 API · NumPy · Gemini API · FastAPI · React · SQLite

LadderGuard — MT5 Trade Manager & Account Guard

MQL5 Expert Advisor See the product page On MQL5 Market

One Expert Advisor on one chart that manages every open position, manual or opened by other EAs, and guards the whole account, with an on-chart panel.

  • Targets in multiples of the stop distance (R): 40% closed at TP1, 30% at TP2, stop to break-even plus a few points, then a ladder that moves the stop one level behind each further level. Optional close-all at a set server time.
  • Account guard: daily loss limit (% or money), maximum drawdown from the peak or static from the start (prop-firm style), and a cap on new trades per day. A breach closes the positions and locks trading.
  • 43/43 unit tests; verified in the MT5 Strategy Tester (partials, break-even, ladder, every lock, timed close) and live on a demo account.

Service See a sample
